# PERSONA — 인물 티어 스튜디오

React + Vite 기반 인물 티어리스트. 이름과 특징 태그, S/A/B/C/D 티어 및 미배치 목록을 관리합니다.

## Docker 실행

Docker Desktop을 실행한 뒤 이 프로젝트 폴더에서:

```sh
docker compose up -d --build
```

접속: http://127.0.0.1:5000

기존 `npm start` 서버가 실행 중이면 먼저 Ctrl+C로 종료하세요(5000 포트 충돌 방지).
기존 `data` 폴더를 컨테이너에 연결하므로 저장된 `data/tierlist.json`을 그대로 사용합니다. 데이터는 이미지에 포함되지 않으며 컨테이너 삭제·재빌드 후에도 호스트 폴더에 남습니다.

```sh
docker compose down       # 종료
docker compose up -d      # 다시 실행
docker compose logs -f    # 로그 확인
```

코드 수정 후에는 `docker compose up -d --build`로 다시 빌드하세요.

## 실행

```sh
npm install
npm run build
npm start
```

`npm run build`로 dist 정적 사이트를 생성합니다. `npm test`로 JSON 검증 테스트를 실행합니다.

로컬 주소: http://127.0.0.1:5000 (이 컴퓨터에서만 접근 가능). 서버가 실행 중일 때 사용할 수 있으며, 종료는 터미널에서 Ctrl+C를 누르세요. 재실행은 `npm start`, 소스를 수정했다면 먼저 `npm run build`를 실행하세요. 개발 중에는 `npm start`와 함께 `npm run dev`를 실행하면 5173 포트에서 자동 갱신을 사용할 수 있습니다. 포트가 사용 중이면 다른 포트로 변경하지 않고 오류를 표시합니다.

서버에 저장 파일이 없으면 처음 접속한 브라우저의 기존 저장 데이터를 이관합니다. 기존 데이터를 사용했던 주소에서 먼저 접속하세요. 다른 주소의 데이터는 JSON 내보내기/가져오기로 옮길 수 있습니다. 같은 서버로 연결된 주소들은 같은 JSON 파일을 사용합니다.

## 기능

- 인물 추가, 수정, 삭제 / 드래그로 티어 및 순서 변경
- 카드의 선택 메뉴로 모바일·키보드 티어 이동
- 이름·태그 검색 및 태그 필터
- JSON 가져오기·내보내기 및 직접 편집, 형식 검증
- 로컬 서버 JSON 파일 자동 저장, 최근 20회 변경 되돌리기

## JSON 형식

```json
{"version":1,"title":"나의 인물 티어리스트","people":[{"id":"unique-id","name":"김도윤","tags":["리더십","전략가"],"tier":"S"}]}
```

`id`는 고유 문자열, `tier`는 S/A/B/C/D 또는 null(미배치). people 배열 순서가 카드 순서입니다. 최대 1,000명, 이름 40자, 태그는 최대 8개/각 20자, 제목 100자. 가져오기는 교체 확인 후 적용됩니다.
데이터는 `data/tierlist.json`에 자동 저장됩니다. 서버를 종료하고 다시 실행해도 유지됩니다. 브라우저 저장소는 보조 백업으로 사용합니다. 초기 인물은 가상 예시입니다.

티어 이름을 클릭하면 수정할 수 있습니다(최대 20자). JSON의 `tierNames` 객체에 저장되며 인물의 `tier` 값은 기존 S/A/B/C/D ID를 유지합니다. `tierNames`가 없는 기존 JSON도 불러올 수 있습니다.

저장 완료 표시는 서버 파일 쓰기가 끝난 뒤 표시됩니다. 저장 오류에는 다시 저장 버튼이 나타납니다. 파일 읽기 오류에는 초기 데이터를 덮어쓰지 않고 오류를 표시합니다. `node scripts/check-persistence.mjs`로 임시 파일을 사용하는 재시작 저장 검증을 실행할 수 있습니다(임시 포트를 사용합니다).



티어는 1~20개까지 추가·삭제할 수 있습니다. 보드 위의 티어 추가 버튼, 티어 이름 클릭으로 이름 수정·삭제, ↑/↓ 버튼으로 순서 변경을 지원합니다. 삭제한 티어의 인물은 미배치로 이동합니다. JSON의 `tierOrder`는 티어 ID 순서, `tierNames`는 이름입니다. 기존 JSON은 기본 S/A/B/C/D 순서로 불러옵니다.
